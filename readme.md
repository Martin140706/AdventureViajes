# 🌍 Adventure Viajes

Adventure Viajes es una aplicación web para la reserva de vuelos, autos y paquetes turísticos, inspirada en plataformas como Despegar.

Este proyecto fue desarrollado para una olimpiada escolar, donde obtuvo el segundo puesto, y actualmente forma parte de mi portfolio personal.

---

## ✨ Funcionalidades

- Registro e inicio de sesión de usuarios  
- Panel de administrador para aceptar y rechazar pedidos  
- Carrito de compras  
- Sistema de pedidos  
- Envío de correos con el estado del pedido  
- Base de datos con MySQL  
- Cambio de moneda (USD, Real, Peso Argentino y Euro)  
- Persistencia del tipo de moneda entre páginas  

---

## 🛠️ Tecnologías

- Node.js  
- MySQL  
- HTML  
- CSS  
- JavaScript  
- Nodemailer  

---

## ⚙️ Instalación

1. Clonar el repositorio
2. Instalar dependencias con:
npm install

Crear archivo .env con las variables necesarias
Iniciar MySQL (XAMPP)
Ejecutar npm start
El servidor estará disponible en: http://localhost:3000
